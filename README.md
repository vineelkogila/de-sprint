# Data Engineering Sprint

A 60-day hands-on journey to become job-ready in Data Engineering.

## Tech Stack

- Python
- SQL
- PostgreSQL
- Docker
- Apache Spark
- PySpark
- Delta Lake
- Databricks
- Apache Airflow
- dbt
- AWS S3
- Git & GitHub

## Projects

### 01 - Batch Data Pipeline
Python → API → PostgreSQL → Airflow

### 02 - Lakehouse
AWS S3 → Spark → Delta Lake → Databricks

### 03 - E-commerce Data Platform
API/Events → S3 → Airflow → Spark → Delta → dbt → Analytics

## Learning Goals

- Build batch and incremental pipelines
- Understand distributed processing with Spark
- Learn orchestration with Airflow
- Build lakehouse architectures
- Implement data quality and testing
- Understand CI/CD for data pipelines
- Develop Data Engineering system-design skills
